# jankenpo-rust


## Documentação da linguagem

O site oficial está numa página pública da linguagem.


## Instalação

```
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

Esse comando está descrito na página de instalação do site oficial.


## Curso

Existe um curso introdutório na plataforma de cursos online. Ele tem outras partes, que aparecem pela busca do próprio site.


## Executando

Estando na pasta do projeto:

```
cd jankenpo-rust
```

Depois:

---


```
cargo run
```
